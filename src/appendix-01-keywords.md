## 付録A：キーワード

<!--
The following keywords are reserved in Lime:
-->

Limeでは以下のキーワードが予約されています:

| キーワード | 説明 |
|----------|------|
| `fn` | 関数宣言 |
| `lime` | 非同期関数宣言 |
| `struct` | 構造体宣言 |
| `interface` | インターフェース宣言 |
| `state` | state宣言（bareバリアント） |
| `enum` | enum宣言（型付きバリアント） |
| `let` | 変数バインディング |
| `mut` | 可変バインディング |
| `if` | 条件分岐 |
| `elif` | 結合条件分岐 |
| `else` | 既定分岐 |
| `while` | ループ |
| `for` | 繰り返しループ |
| `in` | 範囲/リスト反復 |
| `match` | パターンマッチング |
| `return` | 関数からの戻り |
| `defer` | 遅延実行 |
| `await` | 非同期関数の呼び出し |
| `extern` | 外部関数宣言 |
| `true` | ブールリテラル |
| `false` | ブールリテラル |
| `Some` | Optionバリアント |
| `None` | Optionバリアント |
| `try` | タプルパターン |
| `catch` | ワイルドカードパターン |
| `and` | 論理AND |
| `or` | 論理OR |
| `not` | 論理NOT |
| `where` | 型制約 |
| `unsafe` | 安全でないコードブロック |
