## 付録B：演算子と記号

<!--
### Arithmetic Operators
-->

### 算術演算子

| 演算子 | 意味 |
|--------|------|
| `+` | 加算 / 文字列連結 |
| `-` | 減算 |
| `*` | 乗算 |
| `/` | 除算（切り捨て） |
| `%` | 剰余 |

<!--
### Comparison Operators
-->

### 比較演算子

| 演算子 | 意味 |
|--------|------|
| `==` | 等しい |
| `!=` | 等しくない |
| `<` | 小さい |
| `>` | 大きい |
| `<=` | 以下 |
| `>=` | 以上 |

<!--
### Logical Operators
-->

### 論理演算子

| 演算子 | 意味 |
|--------|------|
| `and` | 論理AND |
| `or` | 論理OR |
| `not` | 論理NOT |
| `&&` | 論理AND（記号版） |
| `\|\|` | 論理OR（記号版） |
| `!` | 論理NOT（記号版） |

<!--
### Assignment Operators
-->

### 代入演算子

| 演算子 | 意味 |
|--------|------|
| `=` | 代入 |
| `+=` | 加算代入 |
| `-=` | 減算代入 |
| `*=` | 乗算代入 |
| `/=` | 除算代入 |

<!--
### Other Symbols
-->

### その他の記号

| 記号 | 意味 |
|--------|------|
| `..` | 範囲 |
| `?` | Option型サフィックス（`T?` = `Option(T)`） |
| `::` | 名前空間パス |
| `:` | コロン（型注釈、ブロック開始） |
| `->` | 戻り型（一部使用） |
| `//` | コメント |
| `/* */` | ブロックコメント |
| `#` | コメント |

<!--
### Operator Precedence
-->

### 演算子の優先順位

<!--
From highest to lowest:
-->

高い順に:

1. `not` `!`
2. `*` `/` `%`
3. `+` `-`
4. `<` `>` `<=` `>=`
5. `==` `!=`
6. `and` `&&`
7. `or` `||`
