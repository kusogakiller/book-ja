## Appendix C: Error Codes

## 付録C：エラーコード

<!--
Lime uses error codes for diagnostic messages. The main categories are:
-->

Limeは診断メッセージにエラーコードを使用します。主なカテゴリは以下の通りです:

<!--
### Lexer Errors
-->

### レキサーエラー

| コード | 説明 |
|------|-------------|
| `E0001` | 無効なトークンまたはリテラル |

<!--
### Parser Errors
-->

### パーサーエラー

| コード | 説明 |
|------|-------------|
| `E0101` | 構文エラー |

<!--
### Type Errors
-->

### 型エラー

| コード | 説明 |
|------|-------------|
| `E0201` | 未定義の変数 |
| `E0202` | 未知の関数 |
| `E0203` | 未知のフィールド |
| `E0204` | 未知のメソッド |
| `E0205` | タプルインデックスが範囲外 |
| `E0206` | 非タプルへのインデックス |
| `E0207` | 引数の数が正しい |
| `E0208` | 引数の型が一致しない |
| `E0209` | 非網羅的なmatch |

<!--
### Codegen Errors
-->

### コード生成エラー

| コード | 説明 |
|------|-------------|
| `E0401` | LLVM IRの書き出しに失敗 |
| `E0402` | 未ローワリングの関数 |

<!--
### Linker Errors
-->

### リンカーエラー

| コード | 説明 |
|------|-------------|
| `E0501` | ビルドが実行ファイルを生成しなかった |

<!--
### Runtime Errors
-->

### ランタイムエラー

| コード | 説明 |
|------|-------------|
| `E0601` | ランタイムエラー |

<!--
### Memory Errors
-->

### メモリエラー

| コード | 説明 |
|------|-------------|
| `E0701` | メモリ分析エラー |

<!--
### Example Error Message
-->

### エラーメッセージの例

```
error[E0201] hello.lime:2:1
  |
2 | println(xyz)
  | ^
Type error: undefined variable 'xyz'
  = help: did you mean 'x'?
```
