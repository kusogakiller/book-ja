# 関数とクロージャ

<!--
Functions and closures are two fundamental building blocks in Lime. Functions
are named blocks of code that can be called with arguments. Closures are
anonymous functions that can capture variables from their surrounding scope.
-->

関数とクロージャはLimeにおける2つの基本的な構成要素です。関数は引数で呼び出すことができる
名前付きコードブロックです。クロージャは周囲のスコープから変数をキャプチャできる
匿名関数です。
