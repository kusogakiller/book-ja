# ジェネリック型とインターフェース

<!--
Generics and interfaces are two powerful features that allow you to write code
that works with multiple types. Generics let you define functions, structs, and
enums that work with any type. Interfaces let you define shared behavior.
-->

ジェネリクスとインターフェースは、複数の型で動作するコードを書くことを可能にする
2つの強力な機能です。ジェネリクスでは任意の型で動作する関数、構造体、enumを
定義できます。インターフェースでは共通の振る舞いを定義できます。
